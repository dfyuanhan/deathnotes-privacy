余生笔记 隐私政策

最后更新：2026年6月8日

「余生笔记」（以下简称"本应用"）由个人开发者（以下简称"我们"）运营。我们高度重视您的隐私保护，在您使用本应用时，我们承诺依照适用法律收集、使用并保护您的个人信息。

一、信息收集

我们收集的信息仅限于为您提供服务所必需的内容，包括：

  • 个人资料：您在引导流程中主动填写的姓名、出生日期、出生时辰、出生地、预期寿命等，用于墓碑生成、AI 评价及个性化内容。
  • 信件内容：您撰写并设定开启日期的"写给未来的信"，内容完全由您自主决定。信封未到期前，内容对包括我们在内的任何第三方均不可见。
  • 墓碑样式数据：您选择或定制的墓碑风格、文字内容，用于在设备本地渲染墓碑图片。
  • 里程碑与遗愿清单：您记录的人生事件和遗愿清单条目，用于个性化展示及 AI 解读。
  • 每日一签：每日随机展示的格言数据，仅为本地随机选取，不涉及任何个人信息。
  • 付费购买信息：通过 Apple IAP（In-App Purchase）处理，由 Apple 负责完成交易，我们仅接收购买状态，不存储您的支付信息。

二、信息存储与安全

  • 您的所有个人数据均存储在您设备的本地存储（UserDefaults）中，并通过您的 iCloud 账户在您本人的设备间同步。
  • 我们不会将您的个人信息存储在我们的服务器上（除 AI 评价功能需调用的 DeepSeek API 外，详见下方）。
  • AI 评价功能通过 DeepSeek API 生成内容。使用前，本应用会在 App 内说明将发送的数据类型、接收方和用途，并在获得您的同意后再发送。DeepSeek 的隐私政策适用，您可访问 https://www.deepseek.com/privacy 了解更多。
  • Apple iCloud 的数据安全由 Apple Inc. 负责保障，详见 Apple 隐私政策。

三、AI 评价功能与第三方 AI 服务

当您主动使用「AI 世人评价」或命理分析等 AI 功能时，本应用会在发送数据前通过应用内弹窗向您说明数据用途，并征得您的同意。只有在您点击「同意并继续」后，本应用才会将相关内容发送至第三方 AI 服务 DeepSeek API。

可能发送至 DeepSeek API 的信息包括：

  • 您主动填写的姓名、出生日期、出生时辰、出生地、预期寿命等个人资料；
  • 您主动填写的墓志铭、人生里程碑、人生大事记、遗愿清单、石头记录等文本内容；
  • 为生成个性化评价所需的派生信息，例如年龄、剩余天数、生命进度等。

上述信息仅用于响应您的请求，生成 AI 人生评价、命理分析和人生复盘内容。本应用不会向 DeepSeek API 发送通讯录、照片、精确定位、健康数据、支付信息或其他与该功能无关的敏感信息。

我们不会将上述 AI 请求内容存储在我们的服务器上。DeepSeek API 作为第三方 AI 服务提供方，其数据处理需遵守 DeepSeek 的隐私政策与安全措施。您可访问 https://www.deepseek.com/privacy 了解更多。

四、信息共享

除以下情形外，我们不会与任何第三方共享您的个人信息：

  • 您主动选择并同意通过 DeepSeek API 使用 AI 评价功能（信息仅用于生成您请求的 AI 内容）。
  • 法律法规要求披露的情形。

五、您的权利

您可以随时通过以下方式行使您的数据权利：

  • 访问与更正：在本应用中直接编辑您的个人资料、墓碑内容及信件。
  • 删除数据：卸载本应用将清除本地所有数据。您也可在应用内删除特定内容。
  • iCloud 同步：如需清除 iCloud 中存储的同步数据，请在 iCloud 设置中管理。

六、儿童隐私

本应用不面向未满18岁的未成年人，我们不会故意收集未成年人的个人信息。

七、第三方服务

  • DeepSeek API：用于 AI 评价内容生成，适用 DeepSeek 隐私政策。
  • Apple In-App Purchase：付费订阅由 Apple 处理，适用 Apple 订阅条款。
  • Apple iCloud：数据同步服务，适用 Apple iCloud 服务条款及隐私政策。

八、隐私政策更新

我们可能不时更新本隐私政策。如有重大变更，我们将在应用内通过适当方式通知您。建议您定期查阅本页以了解最新内容。
